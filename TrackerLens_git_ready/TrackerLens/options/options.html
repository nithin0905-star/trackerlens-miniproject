Privacy Information

How TrackerLens handles your data.

📦 All Data Stays Local

TrackerLens stores all audit data exclusively in your browser using IndexedDB. No data is ever transmitted to external servers, cloud services, or any third party.

🚫 No Remote Connections

TrackerLens makes no outbound network requests for its core functionality. The tracker database and all fonts are bundled locally. No telemetry, no analytics, no reporting.

  • All fonts (Inter, JetBrains Mono) are loaded from the extension bundle.
  • Favicons in the popup use a local fallback icon to protect your browsing history.

👁️ What is Observed

TrackerLens observes (but never modifies or blocks):

  • Outgoing HTTP request URLs to detect tracker domains
  • Set-Cookie response headers to classify cookies
  • Privacy-sensitive JavaScript API calls (canvas, WebGL, AudioContext, etc.)
  • Consent banner presence and structure in the DOM

🔑 Permissions Explained

  • tabs — Read the URL of the active tab to identify the site
  • webNavigation — Detect when you navigate to a new page
  • webRequest — Observe (read-only) outgoing requests to detect trackers
  • storage — Save lightweight settings in chrome.storage
  • cookies — Read (not modify) cookies for audit purposes
  • activeTab — Access the current tab when the popup is open
  • <all_urls> — Required for webRequest to observe cross-origin requests

🛡️ Your Controls

You can export all your data, clear it at any time, or perform a factory reset from the Storage & Export section. TrackerLens respects your autonomy over your local data.
